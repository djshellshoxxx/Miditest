1. Grab a copy

Each option produces a full working copy of this site. Pick whichever fits where you want to host it.

2. Host it somewhere (60 seconds each)

Any Linux box or VPS (fastest, paste one thing)
  1. Click Copy shell installer above.
  2. Paste it into your terminal and press Enter. It creates a folder mirror-me with every file.
  3. Serve it: cd mirror-me && python3 -m http.server 8080
  4. Open http://your-server-ip:8080/. For HTTPS use Caddy: caddy file-server --domain example.com --root .
GitHub Pages
  1. Create a new repository and upload the unzipped files (drag and drop works on the GitHub web UI).
  2. Go to Settings, then Pages, choose Deploy from a branch, pick main and / (root).
  3. Your copy appears at https://USER.github.io/REPO/.
Netlify Drop (no account steps beyond signup)
  1. Unzip the download.
  2. Drag the folder onto app.netlify.com/drop.
  3. You get a live URL straight away.
Cloudflare Pages
  1. Workers & Pages, then Create, then Pages, then Upload assets.
  2. Upload the unzipped folder, deploy.
IPFS (no single host to take down)
  1. Install IPFS, then run ipfs add -r mirror-me.
  2. The last hash printed is the folder. Open it via any gateway as /ipfs/HASH/, or pin it on a pinning service.
No host at all
  1. Download the single file version.
  2. Double-click it. It runs from your disk, and can still make more copies of itself.
  3. Pass it on by email, chat, or USB stick.

3. Install it (works offline afterwards)

Install this as an app and it keeps working with no connection and no server, and can still re-export itself.

If there is no install button: in Chrome/Edge use the address bar install icon, on iOS use Share, then Add to Home Screen.

4. Verify your copy

Anyone can publish a tampered mirror. Compare these SHA-256 hashes with ones you trust (for example from the original repo or a signed message). If they match, the copy is identical.

Why this is safe to run

  • No third-party scripts, fonts, analytics or CDNs. Every file is in the bundle.
  • A strict Content-Security-Policy blocks all outside connections. You can read it in the page source.
  • Nothing is sent anywhere. Zips and scripts are built in your browser.

## MIDItest 0.2.0 Beta (Windows)

The first desktop build of **MIDItest by Circuit Drift Labs**: a local MIDI monitor and controller diagnostic bench. It's the same app as https://djshellshoxxx.github.io/Miditest/, packaged so it runs offline without a browser.

### Downloads

| File | What it is |
| --- | --- |
| `MIDItest-Setup-0.2.0-beta-x64.exe` | Installer (per-user, choose install folder, Start menu shortcut) |
| `MIDItest-0.2.0-beta-x64-portable.exe` | Portable single file; nothing to install, just run it |

Requires 64-bit Windows 10 or 11.

### First run

1. Run either exe. The build is **not code-signed**, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
2. Plug in your MIDI controller, then click **Enable MIDI**. Click **Enable SysEx** only if you need SysEx capture.
3. Choose your controller under **Input**, then press **Start Guided Test** or open the **Monitor** tab.

### What's in this beta

- Guided controller test (11 steps, with skip/back/end; skipped steps are reported as untested)
- Live monitor with search, device/channel/type filters, raw/decoded views, CSV/JSON export
- Automatic inventory: keys, continuous controls, buttons/switches, relative encoders, pitch bend, pedals, aftertouch, program change, clock, 14-bit CC, RPN/NRPN, SysEx, MPE-like activity
- Control analysis: range/coverage, unique/skipped/repeated values, stationary jitter, jumps, reversals, dead zones, encoder type, value graph and histogram, per-control capture reset
- Keybed: expected range, unseen keys, held notes and chord names, duplicate/unmatched notes, velocity statistics per key and overall
- Pitch bend panel (travel, asymmetry, resting center and center-return spread); sustain pedal transitions and bounce detection
- MIDI clock BPM (median and rolling), interval jitter and histogram, transport, song position; note timing statistics; traffic-flood detection
- Output tester (Note, CC, Program, Pitch Bend), panic for one channel or all channels, loopback test with round-trip latency statistics
- MIDI Learn, editable mapping worksheet (CSV/JSON/print)
- Diagnostic report with summary, findings, untested areas, baseline save/compare, report import, JSON/CSV export and printing

- **Tests tab**: ten diagnostic tests (protocol audit, link health, key double-trigger, velocity response, rollover, sweep linearity, encoder integrity, pitch-bend return, pedal polarity, loopback burst) with a plain-English "what this result means" for each
- **Windows Logs tab**: read-only scan of the Event Log, Device Manager errors, services, USB selective suspend, setupapi.dev.log and crash reports; runs automatically after tests and explains every MIDI/USB error found; import of scan JSON, setupapi.dev.log and Report.wer files

- **New in 0.2.0:** session record/replay (.miditest-capture.json), per-preset pass/fail checklists with a printable sheet, device profiles and fleet comparison, charts (control, latency, velocity, message rate, pitch), SysEx tools (identity request, send, checksums, dump compare), active send-and-verify tests, MIDI clock generator with sync measurement, second-input path comparison, MIDI 2.0/UMP decoder, offline glossary, self-contained HTML report export, Windows log scan evidence (USB history, USB tree, driver age/signing, recent changes), Labs switches, arrow-key tab navigation.

### Known limitations

- Beta: findings are measured observations, not repair diagnoses.
- Not code-signed (see First run).
- No auto-update. Download new versions from the Releases page.
- Latency figures are browser/MIDI loopback round-trip times, not DAW or driver latency.
